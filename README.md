# کلینیک دامپزشکی مهرگان — قالب لندینگ فارسی

یک صفحه فرود (landing page) کامل، فارسی و راست‌به‌چپ (RTL) برای کلینیک‌های دامپزشکی.
تک‌فایل، بدون نیاز به build یا نصب پکیج — فقط `index.html` را باز یا آپلود کنید.

## انتشار سریع (Publish)

هرکدام از روش‌های زیر را که راحت‌ترید انتخاب کنید:

### ۱) Netlify (ساده‌ترین روش، بدون نیاز به حساب گیت‌هاب)
1. به [app.netlify.com/drop](https://app.netlify.com/drop) بروید.
2. فایل `index.html` را (یا کل همین پوشه) بکشید و در صفحه رها کنید (drag & drop).
3. در چند ثانیه یک لینک عمومی دریافت می‌کنید. بعداً می‌توانید دامنه اختصاصی خودتان را هم وصل کنید.

### ۲) Vercel
1. یک حساب در [vercel.com](https://vercel.com) بسازید.
2. پروژه را به‌صورت "New Project" → "Deploy" آپلود کنید (نیازی به تنظیمات build نیست، نوع پروژه را Static/Other انتخاب کنید).

### ۳) GitHub Pages
1. یک ریپازیتوری جدید در گیت‌هاب بسازید و این فایل‌ها را در آن push کنید.
2. در تنظیمات ریپازیتوری: Settings → Pages → Branch را روی `main` و پوشه را روی `/root` قرار دهید.
3. آدرس سایت به‌صورت `https://username.github.io/repo-name/` در دسترس خواهد بود.

### ۴) هاست اشتراکی / سرور شخصی
فایل `index.html` را از طریق FTP یا پنل هاست در پوشه اصلی سایت (`public_html` یا `www`) آپلود کنید. نیازی به هیچ نصب یا تنظیم دیگری نیست.

## سفارشی‌سازی برای کلینیک‌های دیگر

راهنمای کامل داخل خود فایل `index.html` در یک کامنت HTML در ابتدای فایل قرار دارد. خلاصه‌اش:

- **نام کلینیک**: عبارت «کلینیک دامپزشکی مهرگان» را در سراسر فایل جستجو/جایگزین کنید.
- **رنگ‌ها**: همه رنگ‌ها متغیرهای CSS در بخش `:root` هستند (`--primary`, `--accent`, `--brick` و ...).
- **تماس/آدرس/ساعات کاری**: کلاس‌های `.js-phone` و `.js-address` و جدول ساعات کاری در بخش «تماس با ما».
- **تصاویر**: عکس‌های فعلی نمونه‌های رایگان از Pexels هستند برای نمایش طراحی — قبل از انتشار نهایی، `src` هر `<img>` را با عکس واقعی کلینیک جایگزین کنید (نسبت تصویر هر باکس را حفظ کنید).
- **خدمات، تیم پزشکی، نظرات**: هر کارت یک بلوک مستقل و تکرارشونده است؛ کپی/حذف/ویرایش هر کدام تأثیری روی بقیه ندارد.

## نکات فنی

- بدون وابستگی خارجی به‌جز فونت وزیرمتن (Vazirmatn) از Google Fonts.
- ریسپانسیو کامل (موبایل، تبلت، دسکتاپ).
- انیمیشن‌ها به‌طور خودکار برای کاربرانی که `prefers-reduced-motion` را فعال کرده‌اند غیرفعال می‌شوند.
- سوالات متداول با تگ بومی `<details>` پیاده‌سازی شده‌اند (بدون نیاز به جاوااسکریپت اضافه، در دسترس برای صفحه‌خوان‌ها).

## نقشه محل کلینیک

بخش نقشه هنوز placeholder است چون به آدرس واقعی شما نیاز دارد. برای افزودن نقشه واقعی گوگل:
1. در [Google Maps](https://maps.google.com) آدرس کلینیک را جستجو کنید.
2. Share → Embed a map → کد `<iframe>` را کپی کنید.
3. آن را جایگزین باکس `.map-placeholder` در `index.html` کنید.
